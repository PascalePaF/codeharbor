# CodeHarbor V1.0.2

V1.0.2 重构了验证码工作台和视觉系统，并建立从 GitHub Releases 直接在安装版内部完成更新的链路。

## 主要变化

- 全新三栏验证码工作台：左侧逐邮箱查询，中间只显示发件方、验证码和用途，右侧实时显示 2FA。
- “立即扫描全部邮箱”批量查询全部已启用账户，普通邮件数字必须具备登录或身份验证语境才会显示。
- 邮箱和 2FA 页面均支持独立的密码加密导入、导出；设置页继续提供全量迁移。
- 加密备份使用随机盐 scrypt 和 AES-256-GCM，导入先验证密码及完整性。
- 新增黑夜与白天高对比度主题、清晰中文字体、可见滚动条和 2FA 字段 PNG 帮助图标。
- 安装版自动检查 GitHub 最新版本，下载完成后自动安装并重启。

## 自动更新说明

- V1.0.2 是自动更新的起点，V1.0.1 需要手动安装本版本一次。
- 后续安装版会读取 Release 中的 `latest.yml` 和 `.blockmap`，在软件内部完成更新。
- 便携版不会自动替换自身，设置页会明确提示使用安装版。
- 更新不会删除安装目录中的 `CodeHarbor-Data`。

## 下载文件

- `CodeHarbor-Setup-1.0.2-x64.exe`：Windows x64 安装版，推荐。
- `CodeHarbor-Portable-1.0.2-x64.exe`：Windows x64 便携版。
- `latest.yml` 与 `CodeHarbor-Setup-1.0.2-x64.exe.blockmap`：安装版自动更新元数据。
- `SHA256SUMS.txt`：人工校验安装包。

当前安装包尚未使用商业代码签名证书，Windows SmartScreen 首次运行时可能显示提示。
