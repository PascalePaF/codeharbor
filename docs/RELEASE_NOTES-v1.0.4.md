# CodeHarbor V1.0.4

V1.0.4 重构了桌面与移动端界面的响应式布局，并按用户反馈调整验证码位置。

## 主要更新

- 修复 Windows 安全软件或企业网络代理进行 TLS 检查时的 IMAP 证书误报；应用会同时信任内置根证书和操作系统明确受信任的根证书，并继续严格校验证书链与服务器域名。
- Windows 窗口可缩放至 760×560；界面会在大、中、小窗口间自动切换三栏、两栏或单栏。
- 侧栏在空间不足时自动收为带提示文字的图标栏，邮箱表格自动切换为卡片，不再依赖整页横向滚动。
- 标题、正文、表单、弹窗、验证码、页面留白和卡片间距会在可读范围内随窗口平滑调整。
- 邮箱验证码移动到邮件卡右侧“用途说明”下方，窄窗口仍保持右对齐并自动换行。
- Android、iPhone 与 macOS 同步优化窄屏标题、折叠搜索框、长名称邮箱卡片、验证码卡片、大字体 2FA、编辑弹窗与横屏扫码框。
- 修复相同验证码复制状态串联、剪贴板失败仍显示复制成功、Flutter 页面切换后搜索词残留等问题。

## Windows 下载

- `CodeHarbor-Setup-1.0.4-x64.exe`：推荐安装版，可通过应用内更新继续升级。
- `CodeHarbor-Portable-1.0.4-x64.exe`：免安装便携版。
- `SHA256SUMS.txt`：安装包校验值。

本版本仍未使用商业代码签名证书，Windows SmartScreen 可能在首次运行时显示提示。更新或迁移前请先导出密码加密备份。

## 测试范围

Windows 自动测试覆盖 1280×760、900×650 和 760×560，并检查全页面横向溢出、收件箱栏数、验证码位置、三点菜单、弹窗与字号边界。Flutter 组件测试覆盖 320×568 至 1440×900、手机横屏、200% 字体、长账户名和 8 位 2FA；Android、iOS Simulator 与 macOS 继续由 GitHub Actions 编译，并通过 Android/iPhone 模拟器和 macOS 包验证。
